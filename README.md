## 应用介绍

FrenchEase是一款专为中文用户打造的法语学习应用，完美匹配Edito教材，精选每单元重要单词和语法并提供详解。使用Edito的学习者可快速掌握书中内容并高效复习；使用其他教材的用户也能通过强大搜索功能轻松查找特定语法点（如COD、CIOI）和主题词汇（如天气、服装）。您的法语学习好帮手！

## 主要功能

- **法汉翻译**：即时翻译法语单词和短语
- **分级词汇学习**：A1、A2、B1级别词汇内容
- **语法学习**：清晰的法语语法解析
- **自定义收藏夹**：创建个人词汇收藏
- **主题定制**：个性化应用外观
- **智能搜索**：通过单词、语法点或页码快速查找内容
